#### 7.1 Statistical Integrity (The Anchored Median)
- **P50 Trajectory**: The "Median" line represents the fictitious path connecting the **median value of each individual month** across 1,000 simulations (Cross-Sectional).

- **Zombie Explanation**: The "Solvent Companies" count may fluctuate (e.g., 2 -> 1 -> 2) on the P50 line because the median run in Month X might be different from the median run in Month Y. This is mathematically correct for a cross-sectional view.

- **Relative Time**: The system uses **Integers** for months (e.g., Month 1, Month 12).
- **Anniversaries**: Annual changes are applied in the anniversary month, calculated as `(m - role.start_month) / 12`.

1.  **String-Decimal Standard:** All Currency, Decimals, and Percentages MUST be transmitted as **Strings** (e.g., `"1250.50"`, `"3.0"`).
2.  **Solvency Arrays:** `solvent_counts` arrays (e.g., `p50_solvent_count`) are **MANDATORY** (`Vec<i32>`). They must never be `Option` or `null`.
3.  **Scoped Naming:** Fields must be scoped (e.g., `role_name`, `expense_name`) and never simply `name`.

## 7. Simulation & Business Logic

#### 7.1 Statistical Integrity (The Anchored Median)
- **P50 Trajectory**: The "Median" line represents the fictitious path connecting the **median value of each individual month** across 1,000 simulations (Cross-Sectional).
- **Metric Alignment**: Runway, Valuation, and Net Value labels must be derived from this specific monthly median trajectory.
- **Zombie Explanation**: The "Solvent Companies" count may fluctuate (e.g., 2 -> 1 -> 2) on the P50 line because the median run in Month X might be different from the median run in Month Y. This is mathematically correct for a cross-sectional view.

#### 7.2 Fund Level Logic
- **Relative Time**: The system uses **Integers** for months (e.g., Month 1, Month 12).
- **Anniversaries**: Annual changes are applied in the anniversary month, calculated as `(m - role.start_month) / 12`.
- **Hard-Stop Insolvency**: If `is_solvent` becomes false, all flows and cash snap to `0.00`.
